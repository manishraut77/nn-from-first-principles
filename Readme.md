Neural Network from Scratch

A lightweight neural network implementation built entirely from scratch in Python. No PyTorch, TensorFlow, or external deep learning frameworks.

Features

Scalar-based automatic differentiation

Computational graphs and backpropagation

Neurons, layers, and multilayer perceptrons (MLPs)

ReLU and Tanh activation functions

Gradient-based optimization support

Project Structure

├── scalar.py     # Autograd engine
├── neurons.py    # Neuron, Layer, and MLP
└── README.md
